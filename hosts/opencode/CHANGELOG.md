# @feneto/lh-opencode

## 0.2.0

### Minor Changes

- b5b055f: Initial release of `@feneto/lh-opencode`, the real, spec-compliant [OpenCode plugin](https://opencode.ai/docs/plugins/) for LeanHarness — boundary enforcement, dangerous-command blocking, and secret-path protection as an npm-installable OpenCode plugin (`opencode.json`'s `"plugin"` array), rather than a locally-copied file.

  Versioned independently from `@feneto/lh` since its compatibility surface is OpenCode's plugin API, not the LeanHarness CLI.
